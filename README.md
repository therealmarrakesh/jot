Jot looks like today's Windows 11 Notepad and works like the classic one: open it, type, save. No AI, no formatting toolbar, no accounts, no settings page.

### Highlights
- Tabs: drag to reorder, or drag a tab out into its own window
- Find and replace, Go to line, word wrap, status bar and zoom
- Light and dark themes: follows Windows, with a one-click toggle
- Opens and saves UTF-8, UTF-16 and ANSI files in their original encoding, just like Notepad
- Full keyboard access to the menus (Alt, F10, Shift+F10)
- A single, portable jot.exe: no installer, nothing written to the registry

### Install
Download `Jot.exe` below and run it.

Jot isn't code-signed yet, so Windows SmartScreen may warn you the first time. Click **More info → Run anyway**.

Requires Windows 11 (64-bit).

Third-party licenses: run `jot.exe --notices`.
